# Hermes Manager - 产品需求文档 (PRD)

## 1. 产品概述

**产品名称：** Hermes Manager
**产品类型：** 移动端 AI 聊天应用
**版本：** 1.0.0
**一句话描述：** 支持多用户群聊、多 Agent 协作的移动 AI 助手

---

## 2. 用户故事

### 2.1 核心用户故事

| 身份 | 需求 | 价值 |
|------|------|------|
| 普通用户 | 注册登录后与 AI Agent 对话 | 获得智能助手服务 |
| 群组用户 | 创建聊天室、邀请成员、与多个 Agent 协作 | 团队协作、知识共享 |
| 高级用户 | 连接自己的 Hermes Gateway 管理 Agent | 定制化 AI 服务 |

### 2.2 功能优先级

| 优先级 | 功能 | 描述 |
|--------|------|------|
| P0 | 用户注册/登录 | 基础认证 |
| P0 | 聊天室消息 | 核心聊天功能 |
| P0 | WebSocket 实时通信 | 消息推送、流式响应 |
| P1 | Agent @提及 | 指定 Agent 响应 |
| P1 | 工具调用可视化 | 看到 Agent 调用了什么工具 |
| P1 | 网关管理 | 添加/删除 Gateway |
| P2 | 邀请码加入 | 分享聊天室 |
| P2 | 消息队列 | Agent 繁忙时排队 |
| P2 | 本地 Profile | 支持本地 AI Profile |

## 3. 功能规格

### 3.1 认证模块

**注册**
- 输入：用户名、密码
- 校验：用户名唯一性、密码强度
- 成功：自动登录，跳转首页
- 失败：显示错误信息

**登录**
- 输入：用户名、密码
- 成功：存储 token，跳转首页
- 失败：显示错误信息
- Token 过期：自动刷新

### 3.2 聊天室模块

**创建聊天室**
- 名称（必填）
- 模式：
  - `broadcast` — 所有 Agent 响应每条消息
  - `mention` — 仅 @提及的 Agent 响应
  - `router` — 路由模式
  - `pipeline` — 管道模式
- 触发 token 数：控制何时触发 Agent
- 最大历史 token：控制上下文长度

**加入聊天室**
- 通过邀请码加入
- 群主邀请

**消息功能**
- 发送文本消息
- 接收 Agent 流式响应
- 显示推理过程 (reasoning.delta)
- 显示工具调用 (tool.started/completed/error)
- 中止正在运行的 Agent
- 打字状态指示器
- 成员进出通知

### 3.3 消息展示

**MessageBubble 组件**
- 用户消息：右侧，蓝色系
- Agent 消息：左侧，带 Agent 名称和头像
- 流式消息：实时更新内容
- 错误消息：橙色，可选中复制
- 被中止消息：显示"已中止"
- Token 统计：输入/输出 token 数
- 工具调用状态：started/completed/error 图标

### 3.4 网关管理

**发现网关**
- 扫描本地网络（端口：8642, 8080, 8443, 3000, 5000）
- 扫描本地 ~/.hermes/ profiles
- 显示在线状态

**添加网关**
- 地址（必填）
- 名称（可选）
- API Key（可选，用于认证）
- 模式：http / local

**测试连接**
- 健康检查
- Agent 列表获取

### 3.5 Agent 管理

**Agent 模型**
- 名称、描述
- 头像
- 所属网关
- Profile 配置

**Agent 操作**
- 创建、编辑、删除
- 添加到聊天室
- 从聊天室移除
- 自动发现：网关无 Agent 时自动从 Gateway 拉取

### 3.6 消息队列

**机制**
- Agent 繁忙时，新消息进入队列
- 显示队列长度
- 用户可中止当前运行

**WebSocket 事件**
- `queue_updated` — 队列状态变化
- `abort` — 用户主动中止

## 5. 数据流

### 5.1 消息发送流程

```
用户输入 → 点击发送
    ↓
WebSocket 发送 {type: "message", content: "..."}
    ↓
服务端 → 验证 token
    ↓
RoomService 保存消息 (sender_type: "user")
    ↓
RunExecutor 调用 Gateway
    ↓
Gateway 返回 SSE 流
    ↓
实时转发给聊天室所有成员
    ↓
WebSocket 推送 {type: "message.delta", content: "..."}
    ↓
客户端流式更新 UI
    ↓
完成后推送 {type: "run.completed"}
```

### 5.2 工具调用流程

```
Agent 需要调用工具
    ↓
服务端推送 {type: "tool.started", tool: "...", arguments: {...}}
    ↓
客户端显示"工具调用中"
    ↓
工具执行完成 {type: "tool.completed", output: "...", duration: 123}
    ↓
显示工具结果
```

## 6. 错误处理

### 6.1 网络错误
- 请求失败 → Toast 提示"网络错误"
- 重试机制：自动重试 3 次

### 6.2 认证错误
- Token 过期 → 自动刷新
- 刷新失败 → 跳转登录页

### 6.3 消息错误
- 消息发送失败 → 显示错误状态
- Agent 运行失败 → 显示 "错误: {具体信息}"
- 被中止 → 显示"已中止"

### 6.4 网关错误
- 连接失败 → "网关不可达"
- 认证失败 → "API Key 无效"
- Agent 获取为空 → "网关无可用 Agent"

## 7. 非功能性需求

### 7.1 性能
- 消息列表滚动：60fps
- 消息发送延迟：< 500ms
- 流式响应：首字延迟 < 1s

### 7.2 安全
- 密码 Argon2 加密存储
- JWT 短期有效
- CORS 限制

### 7.3 可用性
- 断网重连：自动重连 WebSocket
- 消息持久化：SQLite 本地存储
- Token 刷新：静默自动刷新
