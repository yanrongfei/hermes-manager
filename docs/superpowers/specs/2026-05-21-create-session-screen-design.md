# 1. 概述

## 1.1 背景

PRD v3.1 要求将 1:1 聊天和群聊合并为统一会话模型，需要重新设计创建会话的交互流程。

## 1.2 核心交互逻辑

| 选择情况 | 结果 |
|----------|------|
| 单选 1 个 Agent | 创建 1:1 会话，mode = 'direct' |
| 多选 N 个 Agent | 创建群聊，显示模式选择（broadcast/mention/router） |

# 5. 模式选择设计

## 5.1 三个模式选项

| 模式 | 文字 | 描述 | 默认 |
|------|------|------|------|
| broadcast | 广播 | 所有 Agent 同时响应 | ✅ |
| mention | 指定 | 只有 @ 的 Agent 响应 | - |
| router | 路由 | Gateway 智能判断 | - |

## 5.2 ChoiceChip 样式

```
┌─────────────────────────────────────┐
│ [广播] [指定] [路由]               │
│   ✓        ○       ○               │
└─────────────────────────────────────┘
        gap: 8dp
```

**选中状态**（广播）：
- 背景：#5856D6
- 文字：白色
- 图标：Icons.check（左侧）

**未选中状态**：
- 背景：#2A2A2A
- 边框：1px #3A3A3C
- 文字：#8E8E93

# 10. 技术实现注意事项

## 10.1 状态管理

```dart
class CreateSessionState {
  String name = '';
  List<String> selectedAgentIds = [];
  String mode = 'direct';  // direct / broadcast / mention / router
}
```

## 10.2 Agent 列表数据源

从 `gatewaysNotifierProvider` 获取 Agent 列表，不从 `Message` 获取。

## 10.3 API 调用

```dart
Future<Room> createSession({
  required String name,
  required List<String> agentIds,
  required String mode,
}) async {
  final dio = _ref.read(dioProvider);
  final response = await dio.post('/rooms', data: {
    'name': name,
    'agentIds': agentIds,
    'mode': mode,
  });
  return Room.fromJson(response.data);
}
```

## 10.4 路由跳转

```dart
context.push('/chat/${room.id}?name=${Uri.encodeComponent(room.name)}');
```
