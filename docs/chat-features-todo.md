# 对话功能缺失清单

对比 hermes-web-ui 参考项目，hermes-app 当前缺失的功能和细节。

## P0 - 高优先级（影响基本使用体验）

### 输入区域

- [ ] **Shift+Enter 换行** — 当前 Enter 直接发送，无法换行。web 支持 Shift+Enter 换行，Enter 发送
- [ ] **文件/图片附件发送** — 无法选择和发送图片、文件。web 支持点击上传、拖拽、粘贴图片，带附件预览和删除

### 消息操作

- [ ] **代码块一键复制** — 单个代码块没有复制按钮，只有整个消息复制。web 每个代码块右上角有复制按钮
- [ ] **重新生成/重试** — Agent 回复出错或不满意时，无法重新生成。web 支持重新发送请求

## P1 - 中优先级（提升交互体验）

### 输入区域

- [ ] **Token 用量显示** — 输入框下方缺少 token 使用量和上下文长度进度条，60% 黄色警告，80% 红色警告
- [ ] **斜杠命令自动补全** — 输入 `/` 没有命令提示下拉列表，支持 `/clear`、`/compress`、`/usage`、`/abort`、`/title` 等

### 消息展示

- [ ] **LaTeX 数学公式渲染** — web 用 KaTeX 渲染 `$...$` 和 `$$...$$` 数学公式
- [ ] **Mermaid 图表渲染** — web 支持流程图、时序图等 Mermaid 图表
- [ ] **消息高亮定位** — 从外部点击跳转到某条消息并高亮显示

### 对话管理

- [ ] **会话内搜索** — 无法在对话内搜索消息内容
- [ ] **消息导出** — 无法导出对话记录（JSON/TXT 格式）
- [ ] **会话置顶** — 无法置顶重要对话

## P2 - 低优先级（锦上添花）

### 交互细节

- [ ] **大纲面板** — 从消息标题生成对话大纲，点击跳转到对应消息
- [ ] **批量选择管理** — 批量选择和删除对话
- [ ] **工具调用显示开关** — 全局控制是否显示工具调用过程
- [ ] **压缩进度提示** — 上下文压缩时的进度展示
- [ ] **Agent 在线状态** — 显示 Agent 在线/离线状态指示
- [ ] **未读消息角标** — 对话列表的未读消息数量显示
- [ ] **键盘快捷键** — Cmd/Ctrl+K 搜索会话等全局快捷键

### 流式交互

- [ ] **会话列表滑动操作** — 左滑删除、置顶等快捷操作
- [ ] **消息回复/引用** — 引用某条消息进行回复（web 也未实现，但属于聊天基本功能）
