# 4. 技术实现注意事项

## 4.1 AgentBusyToast

- 使用 `Overlay` + `Positioned` 实现浮层
- 需管理 Toast 队列，避免多个 Toast 重叠
- 建议封装为 `ToastManager.showAgentBusy(context)` 静态方法

## 4.2 InviteCodeSheet

- 使用 `showModalBottomSheet` 实现
- 需传入 `roomId` 和 `inviteCode` 参数
- 复制功能使用 `Clipboard.setData()`
- 分享链接格式：`hermes://join/{roomId}?code={inviteCode}`
